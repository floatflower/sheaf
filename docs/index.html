即時預覽

編輯、雙欄、預覽三種檢視模式。工具列一鍵插入標題、清單、表格、程式碼區塊。

圖表與公式

直接在文件裡寫 Mermaid 流程圖、LaTeX 數學公式與 Chart.js 資料圖表，寫錯會當場標示。

主題與插件

用 CSS 自訂外觀，內建 Default 與襯線的 Manuscript。插件可以加上自己的語法與區塊。

AI 協作

內建 MCP 伺服器，讓 Claude 這類 AI 讀寫目前的文件。修改以逐行差異顯示，你可以逐行接受或拒絕。

PDF 與 HTML 匯出

HTML 可選單一檔案（內嵌）或附資源資料夾（打包），字體只嵌入文件用到的字，檔案很小。

資料夾與分頁

開啟資料夾後在側邊欄瀏覽所有 .md，多個分頁同時編輯，關閉時提醒未存檔。

圖片

一次拖進多張圖片，或貼上連結。本機圖片在預覽與匯出裡都能正確顯示。

多語系與字體

繁體中文、简体中文、English、日本語，跟隨系統語言。內建 Noto 字體，中日韓字形不會錯亂。

安裝說明

  • macOS：目前尚未經過 Apple 公證，第一次開啟會被擋下。請到「系統設定 → 隱私權與安全性」，找到 Sheaf 並按「仍要打開」。
  • Windows：SmartScreen 可能顯示「未知的發行者」，請選「其他資訊 → 仍要執行」。
  • Linux（AppImage）：下載後執行 chmod +x，再直接開啟。Ubuntu 22.04 以後需要先安裝 libfuse2。
  • Linux（.deb）：用 sudo apt install ./檔名.deb 安裝，會自動處理相依套件與沙箱設定。
